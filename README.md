# уДачный сад

Телефонное PWA для семейных садоводов: нарисуйте план участка и годами ведите
память декоративного сада — что где растёт, что с ним происходило и почему
что-то не прижилось.

- Сайт: https://udacha.kdnfx.space
- API: https://pb.kdnfx.space (PocketBase)

## Что умеет

- Вход по электронной почте (регистрация в два поля).
- Несколько участков с размерами в метрах.
- План участка на телефоне и компьютере: дом, постройки, клумбы, деревья,
  кусты, изгороди, дорожки, газон, водоём. Панорама и правка не мешают друг
  другу: касание выбирает, перетаскивание двигает карту, ручки меняют форму.
  Цели касания от 44 px, привязка к сетке 25 см.
- Список растений с сортами, типами и фото.
- Посадка привязана к месту на плане (клумбе, изгороди, газону).
- Журнал по каждой посадке: полив, цветение, обрезка, подкормка, болезнь,
  укрытие на зиму, пересадка, гибель, заметка — с фотографиями.
- История места по годам: что здесь росло раньше и что с ним случилось.
- Общий журнал сада с фильтром по типу события.
- Устанавливается на главный экран (PWA), фотографии кэшируются офлайн.

## Стек

| Часть | Технологии |
| --- | --- |
| Фронтенд | React 19, TypeScript, Vite, Zustand, React Router, vite-plugin-pwa |
| План | SVG + pointer events, своя геометрия (чистые функции) |
| Бэкенд | PocketBase (коллекции + правила доступа, файлы, аутентификация) |
| Тесты | Vitest (геометрия, даты), Playwright (полный путь пользователя) |

## Структура

```
frontend/          — приложение (Vite + React)
  src/lib/         — геометрия, даты, каталог, клиент PocketBase
  src/plan/        — редактор плана: канва, фигуры, состояние
  src/pages/       — страницы: вход, участки, план, растения, журнал, история
  e2e/             — Playwright-сценарий полного пути
backend/           — схема коллекций PocketBase (идемпотентный скрипт + снапшот)
deploy/            — статический сервер, systemd-юниты, скрипт выкладки
```

## Запуск локально

```bash
cd frontend
npm install
npm run dev            # против живого API (VITE_PB_URL переопределяет адрес)
npm run test           # юнит-тесты
npx playwright test    # e2e против локальной сборки
npm run build          # прод-сборка в dist/
```

## Схема данных

`users` → `plots` (участки) → `features` (объекты плана, JSON-фигура в метрах)
и `plantings` (посадки: растение + точка + необязательная привязка к месту) →
`entries` (события журнала с фото). `plants` — личный справочник растений.
Правила доступа: каждый видит только своё (`owner = @request.auth.id` по цепочке).

Схему накатывает `backend/setup-collections.mjs <url> <email> <password>`.

## Выкладка

```bash
./deploy/deploy-web.sh   # сборка + /opt/udacha-web + systemd udacha-web (порт 4173)
```

API работает как systemd-сервис `udacha-api` (PocketBase, порт 8090,
`deploy/udacha-api.service`). Обратный прокси направляет
udacha.kdnfx.space → :4173 и pb.kdnfx.space → :8090.
