# EDITOR.md — редактор плана участка (MVP)

Новый редактор заменяет рисование объектов «по точкам» на Konva-канве.
Причина замены: в старой модели дом рисовался тапами по углам без сетки,
привязки и прямых углов — нарисовать ровный прямоугольник было невозможно.
Точечное рисование выброшено целиком, а не подлатано.

## Модель взаимодействия: «поставил — подвинул»

Объект **не рисуется, а ставится**: выбор типа в меню «Добавить» сразу
создаёт объект стандартного размера в центре экрана, выровненный по сетке
и уже выделенный. Дальше его двигают, тянут за ручки и крутят. Прямые
углы гарантированы конструкцией: дом — это параметрический прямоугольник
(ширина × глубина × поворот), а не набор свободных точек.

### Геометрия и привязка

- Сетка **0,5 м**, включена всегда; кнопка «Магнит» отключает привязку
  (для тонкой подгонки). Линии 0,5 м видны при достаточном зуме,
  метровые — всегда, каждая 5-я метровая — жирнее.
- Перемещение: при повороте, кратном 90°, к сетке привязывается **угол**
  объекта (габарит 2,5 м встанет углом на линию), иначе — центр.
- Размеры: ручки тянут кромку с шагом 0,5 м, противоположная кромка
  стоит на месте. Минимум 0,5 м.
- Поворот: ручка-«леденец» над объектом, шаг **15°** (при выключенном
  магните — 1°). В инспекторе кнопки ±15° и ±90° и точное число.
- Числовой ввод: у дома (и любого прямоугольника) ширина/глубина
  задаются цифрами в инспекторе, шаг степпера 0,5 м.
- Дорожка/изгородь — ломаная с шириной: вершины тянутся по сетке,
  «+ точка» продолжает линию. Привязка вершин к сетке даёт ровные
  горизонтали/вертикали/45° естественным образом.

### Формы объектов

| Тип | Форма | По умолчанию |
|---|---|---|
| Дом (building) | прямоугольник | 6 × 4 м |
| Дорожка (path) | ломаная + ширина | сегмент 4 м, ширина 1 м |
| Клумба (flowerbed) | прямоугольник ⇄ круг | 2 × 1,5 м |
| Композиция (composition) | прямоугольник ⇄ круг | 3 × 2 м |
| Изгородь (hedge) | ломаная + ширина | сегмент 4 м, ширина 0,6 м |
| Дерево (tree) | круг (диаметр кроны) | ⌀ 3 м |
| Куст (shrub) | круг | ⌀ 1,5 м |
| Газон (lawn) | прямоугольник | 4 × 3 м |
| Водоём (water) | прямоугольник ⇄ круг | 2 × 1,5 м |
| Зона света | прямоугольник, полупрозрачная | 4 × 4 м |

У прямоугольных клумб/композиций/водоёмов в инспекторе есть
переключатель формы «Прямоугольник ⇄ Круг».

### Десктоп

- Колесо — зум к курсору, перетаскивание пустого места — панорама.
- Перетаскивание объекта двигает его сразу (порог 4 px отличает клик).
- Клавиши: стрелки — сдвиг на 0,5 м (с Shift — 0,1 м), Esc — снять
  выделение, Delete — удалить, Ctrl/Cmd+Z — отмена, Ctrl+Shift+Z /
  Ctrl+Y — повтор.
- Инспектор — панель справа (≥ 900 px), не перекрывает план.

### Мобильный (≈390 px)

- **Явный переключатель режимов** «Рука / Правка» слева сверху,
  кнопки ≥ 44 px. Рука: один палец — панорама. Правка: один палец —
  выбор и перенос объектов. **Два пальца — всегда** панорама/зум,
  в обоих режимах: жесты не конфликтуют.
- Инспектор — нижняя шторка, план остаётся виден выше неё.
- Ничего не завязано на hover; все ручки выделения имеют зону касания
  ≥ 44 px (визуально меньше, хит-зона прозрачная).

### Отмена / повтор

Каждое законченное действие (постановка, перенос, растяжение, поворот,
удаление, правка полей) — шаг истории (до 50). Undo/Redo — кнопки в
шапке редактора + клавиатура. История локальная на сессию редактора.

### Сохранение

Автосохранение: каждое законченное действие сразу пишется в PocketBase
(последовательная очередь). Индикатор в шапке: «Сохранено ✓ /
Сохранение… / Не сохранилось — повторить». Кнопки «Сохранить» нет —
аудитория 35–65 не должна о ней помнить.

## Зоны света

Слой «Свет» включается кнопкой в шапке. Зона — обычный объект
(прямоугольник, полупрозрачная заливка: солнце/полутень/тень),
редактируется теми же ручками. Живёт в коллекции `lightZones`
(`condition: sunny | partial_shade | shade`). Условие зоны напрямую
соответствует признаку растения `sun_exposure` — см. подбор растений.

## Подбор растений

В инспекторе выделенного объекта (клумба, композиция, дерево, куст,
изгородь, газон) — список активных посадок и кнопка «Посадить».
Открывается каталог растений пользователя (43+ из сида) с фильтрами,
которые уже есть в данных: **месяц цветения** и **освещение**
(`bloom_months`, `sun_exposure`). Если центр объекта попадает в зону
света, фильтр по освещению предлагается автоматически («Это место в
полутени»). Посадка создаёт запись `plantings` + авто-событие журнала —
той же функцией `createPlanting`, что и остальное приложение.

## Хранение (без миграций)

Коллекции и поля PocketBase не меняются. `geometry` — JSON-поле, в него
добавляется необязательный ключ `shape` с параметрической формой:

```jsonc
geometry: {
  "type": "polygon",            // как раньше — для всех старых читателей
  "points": [[x,y], …],         // ВСЕГДА вычисляются из shape
  "shape": {                    // новое, читает только редактор
    "kind": "rect" | "circle" | "line",
    "cx": 10, "cy": 8,          // центр (rect/circle), метры
    "w": 6, "h": 4,             // rect
    "r": 1.5,                   // circle
    "rot": 0,                   // градусы
    "pts": [[x,y], …],          // line: вершины осевой линии
    "width": 1                  // line: ширина, м
  }
}
```

`points` всегда пересчитываются из `shape` (прямоугольник → 4 угла,
круг → 24-угольник, линия → контур с шириной), поэтому просмотр,
экспликация, печать, маркеры посадок и PDF работают без изменений.
Старые объекты без `shape` редактор импортирует: точечные (дерево/куст/
калитка) — как круги, полигоны — как многоугольники (перенос/поворот/
удаление; без параметрических ручек). Прямоугольные полигоны без
поворота распознаются и становятся полноценными rect.

## Интеграция с приложением

- Новый экран `PlotEditor` (`?screen=` state-машина в main.tsx).
- В `GardenDetail` режимы «+ Объект» и «Зоны» удалены; вместо них
  кнопка «Редактировать план», открывающая редактор. Просмотр
  (пан/зум, номера, сезонность, поиск, посадки, PDF) остаётся как был.
- Канва редактора — **SVG + pointer events** (не Konva): геометрия в
  чистых TS-модулях покрывается юнит-тестами, DOM-тестируемость для
  Playwright (data-атрибуты), чёткие линии на любом DPI.

## Вне MVP (сознательно)

- Мультивыделение и группировка.
- Редактирование границы участка произвольной формы (размер участка —
  прямоугольник из ширины/длины, как при создании сада).
- Зоны влажности в редакторе (смотрятся в просмотре, как раньше).
- Freehand-рисование; кривые Безье у дорожек.
- DnD-списки, AI-советник, PDF-отчёт — уже работают, не трогаем.
