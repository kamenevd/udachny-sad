## Этап 4: Новые фичи — Экспорт и теги

- [x] Экспорт плана сада (PDF/PNG):
  - PNG-снимок уже был (ExportPng, Konva `toDataURL` — качественнее html2canvas).
  - Новое: `<ExportReport>` — отчёт «снимок канвы + экспликация + растения с характеристиками», печать/сохранение в PDF через `window.print()`. Без `jspdf`: у него нет кириллицы без вшивания TTF ~1 МБ, печать работает офлайн и без зависимостей.
- [x] Система тегов для растений:
  - Поля в схеме уже были с PLAN12 (`sun_exposure`, `soil_type`, `moisture`) — новых миграций не потребовалось.
  - `<TagFilter>`: чипы с мульти-выбором (ИЛИ внутри категории, И между), цветовая кодировка по плану (солнце=жёлтый/gold, тень=серый, влага=синий/blueink).
- [ ] ~~Drag-and-drop сортировка растений~~ — **отложено сознательно**: список посадок места обычно 1–5 позиций, ценность ручного порядка мала, точный touch-DnD — худший паттерн для ЦА 35–65 на телефоне, а @dnd-kit + поле sortOrder + миграция — ощутимая цена.
